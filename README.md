# Job Radar

Radar local de convocatorias cortas (prácticas, trainee, bootcamps y academies, junior) que avisa por Telegram.

> 🚧 En desarrollo. Ver [PLAN.md](PLAN.md).

## Aviso

Herramienta para **uso personal**. Cada usuario la ejecuta en su equipo y es responsable de respetar las
condiciones de uso de cada portal. Algunas fuentes (p. ej., LinkedIn) no permiten el scraping en sus condiciones:
puedes desactivarlas en `config.yaml`.
